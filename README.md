# EcoExplorer – Sprint 1

Experiencia web 3D educativa (React + Three.js + react-three-fiber).

## Ejecutar
```
npm install
npm run dev
```

- TH-02: Canvas 3D con luces, cámara y controles
- HU-01: pantalla de inicio y entrada al ecosistema
